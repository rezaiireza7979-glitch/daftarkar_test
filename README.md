# دفتر کار — پروژه اندروید

برنامه‌ی فاکتور و گزارش کار. تمام داده‌ها فقط روی خود گوشی ذخیره می‌شود و برنامه به اینترنت نیاز ندارد.

## گرفتن فایل APK

### راه ۱: Android Studio
1. Android Studio را نصب کنید و پوشه‌ی همین پروژه را با Open باز کنید.
2. صبر کنید Sync تمام شود (بار اول اینترنت لازم است).
3. از منوی Build گزینه‌ی Build Bundle(s) / APK(s) و بعد Build APK(s) را بزنید.
4. فایل در این مسیر ساخته می‌شود: app/build/outputs/apk/debug/app-debug.apk

### راه ۲: بدون نصب چیزی، با GitHub
1. در github.com یک مخزن (repository) خالی بسازید و همه‌ی فایل‌های این پروژه را در آن آپلود کنید.
2. به تب Actions بروید و workflow با نام Build APK را اجرا کنید (Run workflow).
3. بعد از چند دقیقه، فایل daftar-kar-apk را از پایین صفحه‌ی همان اجرا دانلود کنید و از داخلش app-debug.apk را بردارید.

## نصب روی گوشی
فایل APK را به گوشی بفرستید و بازش کنید. اگر اندروید پرسید، اجازه‌ی «نصب از منبع ناشناس» را برای همان برنامه (مثلاً مرورگر یا تلگرام) فعال کنید. حداقل نسخه‌ی اندروید ۸ لازم است.

## نکته‌ها
- با حذف برنامه یا پاک کردن اطلاعات آن، داده‌ها از بین می‌رود. از «تنظیمات > گرفتن نسخه پشتیبان» استفاده کنید.
- ظاهر و عملکرد برنامه در فایل app/src/main/assets/index.html است. همین فایل را در مرورگر هم می‌توانید باز کنید و امتحان کنید.
